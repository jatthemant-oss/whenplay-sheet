# WhenPlay Premium

Android app that plays a chosen song, reel or link at a chosen time.
This repository is the **Sheet (UI 8)** build. The old TuneX repository is
untouched, so you can always go back to it.

- Package: `com.whenplay.premium` (installs beside the old app)
- Version: 4.0.0-sheet
- Build: GitHub Actions → Actions tab → newest run → Artifacts → `WhenPlay-Premium-APK`

See `GitHub-Steps.md` for the full upload and build steps.
